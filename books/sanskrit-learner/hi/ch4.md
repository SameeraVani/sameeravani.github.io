# अध्याय ४: संस्कृत शब्दावली (शब्द परिचय)

इस पाठ में हम संस्कृत के सामान्य शब्दों तथा उनके वर्ण-विच्छेद (अक्षरों का विभाजन) को सीखेंगे।

---

## १. वर्णविच्छेद उदाहरण
संस्कृत में प्रत्येक शब्द व्यंजनों और स्वरों के योग से बनता है। इनके विभाजन को वर्णविच्छेद कहते हैं। उदाहरण:
- **अजः** = अ + ज् + अः
- **बालकः** = ब् + आ + ल् + अ + क् + अः
- **कमलम्** = क् + अ + म् + अ + ल् + अ + म्
- **नेत्रम्** = न् + ए + त् + र् + अ + म्
