# ಅಧ್ಯಾಯ ೪: ಸಂಸ್ಕೃತ ಶಬ್ದಕೋಶ (ಪದ ಪರಿಚಯ)

ಈ ಪಾಠದಲ್ಲಿ ನಾವು ಸಂಸ್ಕೃತದ ಸಾಮಾನ್ಯ ಪದಗಳನ್ನು ಹಾಗೂ ಅವುಗಳ ವರ್ಣವಿಚ್ಛೇದವನ್ನು (ಅಕ್ಷರ ವಿಂಗಡಣೆ) ಕಲಿಯುತ್ತೇವೆ.

---

## ೧. ವರ್ಣವಿಚ್ಛೇದ ಉದಾಹರಣೆಗಳು
ಸಂಸ್ಕೃತದಲ್ಲಿ ಪ್ರತಿಯೊಂದು ಪದವು ಹಲ್ಲುಗಳು ಮತ್ತು ಅಚ್ಚುಗಳ ಸಂಯೋಜನೆಯಿಂದ ಸಿದ್ಧಿಸುತ್ತದೆ. ಇವುಗಳ ವಿಂಗಡಣೆಯನ್ನು ವರ್ಣವಿಚ್ಛೇದ ಎನ್ನಲಾಗುತ್ತದೆ. ಉದಾಹರಣೆಗಳು:
- **अजः** = अ + ज् + अः
- **बालकः** = ब् + आ + ल् + अ + क् + अः
- **कमलम्** = क् + अ + म् + अ + ल् + अ + म्
- **नेत्रम्** = न् + ए + त् + र् + अ + म्
