# चतुर्थः पाठः: शब्दपरिचयः वर्णविच्छेदः च (Sanskrit Vocabulary & Letter Splitting)

अस्मिन् पाठे वयं संस्कृते सामान्यान् शब्दान् पठिष्यामः। प्रत्येकं शब्दस्य वर्णानां पृथक्करणं (वर्णविच्छेदः) अपि अत्र दर्शितम् अस्ति।

---

## १. वर्णविच्छेद-उदाहरणाः (Letter Splitting Examples)
संस्कृते प्रत्येकं शब्दः व्यञ्जनानां स्वराणां च संयोगेन सिद्ध्यति। स्वराणां व्यञ्जनानां च विभाजनं वर्णविच्छेदः कथ्यते। यथा:
- **अजः** = अ + ज् + अः
- **बालकः** = ब् + आ + ल् + अ + क् + अः
- **कमलम्** = क् + अ + म् + अ + ल् + अ + म्
- **नेत्रम्** = न् + ए + त् + र् + अ + म्
