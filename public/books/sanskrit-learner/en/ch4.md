# Chapter 4: Sanskrit Vocabulary (शब्दपरिचयः)

In this chapter, we explore common vocabulary words in Sanskrit along with letter splitting (Varnaviccheda) examples.

---

## 1. Letter Splitting Examples
In Sanskrit, words are formed by combining consonants and vowels. Dividing them is called Varnaviccheda. Examples:
- **अजः** = अ + ज् + अः
- **बालकः** = ब् + आ + ल् + अ + क् + अः
- **कमलम्** = क् + अ + म् + अ + ल् + अ + म्
- **नेत्रम्** = न् + ए + त् + र् + अ + म्
