# द्वादशः पाठः: कालपरिचयः

अस्मिन् पाठे वयं संस्कृते **कालः** कथं उच्यते इति पठिष्यामः। दिनस्य भागाः, वाराः (सप्ताहदिनानि), मासाः, ऋतवः, संवत्सरः — एतत् सर्वं संस्कृते जानीमः।

| **सायंकालः** | Evening | १७:०० – १९:०० |

### २.४ व्यावहारिक-सम्भाषण-वाक्यानि (Practical Clock Sentences)

| प्रश्नः / वाक्यम् | संस्कृतम् | English |
| :--- | :--- | :--- |
| समयः कः? | **सम्प्रति कः समयः? / अधुना घण्टा का?** | What time is it now? |
| 7:15 | **अधुना सपाद-सप्तवादनम् अस्ति।** | It is 7:15 now. |
| 7:30 | **अधुना सार्ध-सप्तवादनम् अस्ति।** | It is 7:30 now. |
| 7:40 | **अधुना चत्वारिंशदधिक-सप्तवादनम् अस्ति।**<br/>*(अथवा विंशतिन्यून-अष्टवादनम्)* | It is 7:40 now (20 to 8). |
| 7:45 | **अधुना पादोन-अष्टवादनम् अस्ति।** | It is 7:45 now (quarter to 8). |
| 8:10 | **अधुना दशाधिक-अष्टवादनम् अस्ति।** | It is 8:10 now. |
| कति वादने? | **भवान् कति वादने उत्तिष्ठति?** | At what time do you wake up? |
| 5:30 वादने | **अहं प्रातः सार्ध-पञ्चवादने उत्तिष्ठामि।** | I wake up at 5:30 in the morning. |
| 8:45 वादने | **अहं पादोन-नववादने विद्यालयं गच्छामि।** | I go to school at 8:45. |
| 4:40 वादने | **अहं विंशतिन्यून-पञ्चवादने क्रीडामि।** | I play at 4:40 (20 to 5). |

> **ध्यातव्यम्:**
> - **सपाद** = +१५ निमेषाः (Quarter past)
> - **सार्ध** = +३० निमेषाः (Half past)
> - **पादोन** = -१५ निमेषाः (Quarter to)
> - **अधिकम्** = योजितम् (Past) : यथा *दशाधिकम्* (+१०), *विंशत्यधिकम्* (+२०), *चत्वारिंशदधिकम्* (+४०)
> - **न्यूनम् / ऊनम्** = हीनम् (To / Remaining) : यथा *दशन्यूनम्* (-१०), *विंशतिन्यूनम्* (-२०)

## ९. उपयोगी-सम्भाषणम् — कालविषये (Time-Related Conversations)

**सम्भाषणम् १ — समयः**

**अ:** भवन्, सम्प्रति कः समयः?

**ब:** अधुना सप्तवादनम् अस्ति।

**अ:** अरे! विद्यालयस्य समयः अभवत्। शीघ्रम् गच्छामि।

**ब:** बाढम्। शुभम् भवतु।

---

**सम्भाषणम् २ — वारः**

**अ:** अद्य कः वारः?

**ब:** अद्य गुरुवारः अस्ति।

**अ:** ओह। श्वः शुक्रवारः भविष्यति। शुक्रवारे विद्यालयः न भवति।

**ब:** आम्! अतः श्वः क्रीडितुं गच्छावः!

---

**सम्भाषणम् ३ — मासः ऋतुश्च**

**अ:** अयं कः मासः?

**ब:** अयं श्रावणमासः अस्ति।

**अ:** अतएव अतीव वृष्टिः भवति।

**ब:** आम्। श्रावणमासः वर्षाऋतौ भवति।

**अ:** वर्षाकालः मे प्रियः। हरितं सर्वत्र दृश्यते।

## ११. स्मरणीयाः बिन्दवः (Key Points to Remember)

१. **समयप्रश्नः:** "सम्प्रति कः समयः?" / "अधुना घण्टा का?"
   - **१५ निमेषाः (15 min):** **सपाद-** (उदा. सपाद-त्रिवादनम् = 3:15)
   - **३० निमेषाः (30 min):** **सार्ध-** (उदा. सार्ध-त्रिवादनम् = 3:30)
   - **४० निमेषाः (40 min):** **चत्वारिंशदधिक-** (३:४०) अथवा **विंशतिन्यून-** (चतुर्वादनम्)
   - **४५ निमेषाः (45 min):** **पादोन-** (उदा. पादोन-चतुर्वादनम् = 3:45)

२. **अधिकाः / न्यूनाः निमेषाः:** 
   - अधिकम् = Past (उदा. पञ्चाधिकम् = +5 min, दशाधिकम् = +10 min)
   - न्यूनम् = To (उदा. पञ्चन्यूनम् = 5 min to, दशन्यूनम् = 10 min to, विंशतिन्यूनम् = 20 min to)

३. **वाराणां क्रमः:** रवि → सोम → मङ्गल → बुध → गुरु → शुक्र → शनि

४. **षट् ऋतवः:** वसन्त → ग्रीष्म → वर्षा → शरत् → हेमन्त → शिशिर

५. **द्वादश मासाः:** चैत्र → वैशाख → ज्येष्ठ → आषाढ → श्रावण → भाद्रपद → आश्विन → कार्तिक → मार्गशीर्ष → पौष → माघ → फाल्गुन

६. **पक्षद्वयम्:** प्रत्येकमासे **शुक्लपक्षः** (waxing) च **कृष्णपक्षः** (waning) च भवतः।

७. **ह्यः / अद्य / श्वः** = Yesterday / Today / Tomorrow — एतानि त्रीणि अव्ययानि अत्यन्तं महत्त्वपूर्णानि सन्ति।
