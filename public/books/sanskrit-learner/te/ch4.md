# అధ్యాయము 4: సంస్కృత పదకోశము (పద పరిచయము)

ఈ పాఠంలో మనం సంస్కృతంలోని సాధారణ పదాలను మరియు వాటి వర్ణ విచ్ఛేదములను నేర్చుకుంటాము.

---

## 1. వర్ణ విచ్ఛేద ఉదాహరణలు
సంస్కృతంలో ప్రతి పదము హల్లులు మరియు అచ్చుల కలయిక ద్వారా ఏర్పడుతుంది. వాటిని విడదీయడాన్ని వర్ణ విచ్ఛేదము అంటారు. ఉదాహరణలు:
- **अजः** = अ + ज् + अः
- **बालकः** = ब् + आ + ल् + अ + क् + अः
- **कमलम्** = क् + अ + म् + अ + ल् + अ + म्
- **नेत्रम्** = न् + ए + त् + र् + अ + म्
