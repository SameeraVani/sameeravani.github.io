# அத்தியாயம் 4: சமஸ்கிருத சொற்களஞ்சியம் (சப்தபரிசயம்)

இந்த அத்தியாயத்தில் நாம் அன்றாட சமஸ்கிருத சொற்களையும் அவற்றின் எழுத்துப் பிரிப்பையும் கற்றுக்கொள்வோம்.

---

## 1. எழுத்துப் பிரிப்பு உதாரணங்கள்
சமஸ்கிருதத்தில் சொற்கள் உயிரெழுத்துக்கள் மற்றும் மெய்யெழுத்துக்களின் சேர்க்கையால் உருவாகின்றன. இவற்றைத் தனித்தனியாகப் பிரிப்பது வர்ணவிச்சேதம் எனப்படும். உதாரணங்கள்:
- **अजः** = अ + ज् + अः
- **बालकः** = ब् + आ + ल् + अ + क् + अः
- **कमलम्** = क् + अ + म् + अ + ल् + अ + म्
- **नेत्रम्** = न् + ए + त् + र् + अ + म्
